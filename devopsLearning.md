Que 2 :  What is Cloud Computing?
Ans: Cloud Computing ka matlab hai internet ke through servers, storage, databases, networking aur software ko use    
     karna, bina apna physical server kharide aur maintain kiye.
     Cloud Computing ke main types
    1. IaaS — Infrastructure as a Service
            Aapko virtual servers, networking aur storage milte hain. OS aur application ko kaafi had tak aap manage karte ho.
            Example: AWS EC2, Azure Virtual Machines
    2. PaaS — Platform as a Service
            Platform aapko application deploy karne ki facility deta hai, aur server infrastructure ka kaafi management provider karta hai.
            Example: Azure App Service, Google App Engine
    3. SaaS — Software as a Service
            Ready-made software ko internet se use karte ho. Aapko uska server manage nahi karna padta.
            Example: Gmail, Google Docs
    
    Different Types of Cloud Deployments
    1) Public cloud : A shared cloud environment where multiple users can access services over the internet, like AWS or Azure.
    2) Private cloud : A dedicated cloud environment for one organization, offering more control and privacy.
    3) Hybrid cloud : A mix of public and private clouds, allowing data and applications to move between them for flexibility.

    Few Features commonly offered by cloud providers:
    1) Compute Services
    2) Storage Services
    3) Database services
    4) Networking services
    5) Container services
    6) Serverless Computing
    7) Machine learning Services
    8) Identify And access Management (IAM)  
    9) Monitoring and logging
    10) Content Delivery Network (CDN)
    11) Backup and disaster recovery
    12) Security and compiliance tools
    13) Virtual Private cloud (VPC)
    14) Data Analytics Services
    15) Api managaemnt
